# PREIshare Investor Dashboard Client Brief

## Client Overview

PREIshare is for investors who need a simple way to view important investment information. In this sprint, the investor should be able to quickly see their portfolio value, open deals, and profile without searching through unnecessary information.

## Primary Actors

- Investor
- Future admin (out of scope for this sprint)

## Investor Goals

- Scan portfolio value
- Open and view deals
- View profile information

## Must-Have Dashboard Areas

- Home overview
- Portfolio
- Deals
- Profile

## Success Criteria

- Investor can see the main dashboard information without hunting through clutter.
- Investor can reach Portfolio, Deals, and Profile from a persistent sidebar on desktop.
- The dashboard has a clear and organized layout.
- Each required dashboard area is easy to identify.

## Out of Scope

This sprint is shell-only, so it does not include:

- Real authentication
- Database-backed numbers
- Payment processing
- Full admin functionality
- Production backend features
