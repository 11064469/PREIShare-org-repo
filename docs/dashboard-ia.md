# PREIshare Dashboard Information Architecture

## URL Map

| URL | Page | Navigation Label | Primary Content |
|---|---|---|---|
| /dashboard | Dashboard Home | Home | Portfolio overview, stats, recent activity |
| /dashboard/portfolio | Portfolio | Portfolio | Mock portfolio value and investment holdings |
| /dashboard/deals | Deals | Deals | Mock investment opportunities |
| /dashboard/profile | Profile | Profile | Mock investor profile and account information |

## Page Purposes

### Dashboard Home
**URL:** `/dashboard`

Provides investors with a quick overview of their investment information.

**Primary Content:**
- Mock portfolio statistics
- Portfolio summary
- Recent activity
- Quick overview of important investor information

### Portfolio
**URL:** `/dashboard/portfolio`

Allows investors to review their mock portfolio information and investment holdings.

**Primary Content:**
- Portfolio summary
- Mock portfolio value
- Investment holdings table

### Deals
**URL:** `/dashboard/deals`

Provides a simple view of mock investment opportunities.

**Primary Content:**
- Mock deal list
- Basic deal information
- Clearly labeled placeholder data

### Profile
**URL:** `/dashboard/profile`

Displays basic mock investor and account information.

**Primary Content:**
- Investor name
- Contact information
- Account details

## Navigation

The dashboard navigation contains four items:

- Home
- Portfolio
- Deals
- Profile

The dashboard uses a shared sidebar, header, and main content area.

## Success Criteria

- All four dashboard routes are accessible through navigation.
- Every page displays a clear page title.
- The dashboard includes a sidebar, header, and main content region.
- The layout remains usable on narrow screens.
- Sample investment information is clearly labeled as mock data.
- No live backend data, real authentication, payments, or production financial features are included.
